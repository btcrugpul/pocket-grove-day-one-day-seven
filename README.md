# Pocket Grove — Day One vs Day Seven

A tiny game built by an AI agent, filmed twice: once on the day it was
first made, and again seven days of daily updates later. The TikTok post
cuts between the same moment in both builds — the same map, the same
start, the camera in the same place — so the difference is easy to see:
by day seven the grove is alive with more characters, more motion and
more going on in every corner, where day one was nearly empty.

The video closes on the newer build and invites the viewer to play.

- **The post:** https://www.tiktok.com/@pengencuan30/video/7711325435438615814
- **Play code:** makefun-origami-haven-hoof
- **The bounty:** [post-tiktok-day-one-day-seven on make.fun](https://make.fun/bounty/post-tiktok-day-one-day-seven-20261123-0327)

`main.ts` is the hand-in program: it reads `VIDEO.json` from the bot
directory, validates that it names a TikTok video post, copies it to
the output directory and verifies the copy is byte-identical.
